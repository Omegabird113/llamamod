# 1.3.2
[Released](https://github.com/Omegabird113/llamamod/releases/tag/1.3.2%2Bmc26.1.2) July 6th, 2026

## Changes
- The new build of LlamaBlocks is now for Minecraft `26.1.2` instead of `1.21.8`
- LlamaBlocks is now made using MCreator `2026.2` instead of `2025.3`
- Seeing the reset button in the Password Changer now has the same permission requirement as seeing the password (permission level >=3 and Creative Mode and not just the permission level requirement)
- Improved spacing in the Password Changer UI
- Updated the mod description in the NeoForge about to be more confident
- The LlamaBlocks Documentation now has its own website
- The documentation website has replaced the Modrinth page in the NeoForge about
- Internal code improvements
