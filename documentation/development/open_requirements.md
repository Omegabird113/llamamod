# Requirements to Open the Workspace
In order to open the LlamaBlocks workspace in MCreator after downloading the source code, you need to download the following:

- MCreator version [2026.1](https://mcreator.net/download/2026-1) (*or newer*).

> **Note**:
> 
> The [Remote Workspaces Support](https://mcreator.net/plugin/97468/remote-workspaces-support-20232) plugin has not been updated for MCreator 2026.1. This means that you will need to use Git in a terminal if you want to interact with the actual Git repository.
