# Requirements to Run LlamaBlocks
**26.1.2 build**:

- [Minecraft](https://minecraft.net) version 26.1.2
- [NeoForge](https://neoforged.net/) version [26.1.2.71](https://maven.neoforged.net/releases/net/neoforged/neoforge/26.1.2.71/neoforge-26.1.2.71-installer.jar) or higher

**1.21.1 build**:

- [Minecraft](https://minecraft.net) version 1.21.1
- [NeoForge](https://neoforged.net/) version [21.1.232](https://maven.neoforged.net/releases/net/neoforged/neoforge/21.1.232/neoforge-21.1.232-installer.jar) or higher
