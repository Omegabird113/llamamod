# Diamond Banana
A Diamond Banana is a variant of the banana which is even better than the golden one:

- A nutritional value of `9` *(it heals `4.5` hunger bars)*
- A saturation modifier of `1.1` *(it gives `19.8` saturation points)*
- It can be eaten in `1 second` *(`20 ticks`)*
- It can't be composted or used as furnace fuel

## Crafting
It can be crafted in a Smithing table using a `Diamond Banana Upgrade` in the template slot, the golden banana, and a diamond block.
