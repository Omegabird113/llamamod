# Contibuting Guidelines
- Issues and reviewing any existing prs are perferable to creating new prs.
- LlamaBlocks if made with [MCreator](https://mcreator.net). If prs make changes to the code that are not refelected in the MCreator mod elements or **otherwise appaear to be made outside of MCreator, they will be closed**.

- Be reasonable (follow GitHub's guidlines, treat people humanly, be appropraite, etc)
- Repsonse times may very, as this is a personal project.
- Issues/PRs must be only one issue/feature/request.
- PRs must not fail to build.
- Low Quality or Large Change PRs will likely get closed.
- Finnish your PRs/Issues, or they'll get closed.
